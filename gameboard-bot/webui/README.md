# Gameboard WebUI

TanStack Start app for the `gameboard-bot` playable demos.

**Live demo:** <https://wallchess-webui.mfauzan-az23.workers.dev> — play Wall Chess and International Draughts in the browser, no install.

## Routes

| Route | Purpose |
| --- | --- |
| `/` | Game picker for Wall Chess and International Draughts. |
| `/play` | Wall Chess mode picker. |
| `/game` | Wall Chess board, local friend mode, bot mode, and arena mode. |
| `/checkers` | International Draughts board backed by the Rust/WASM checkers engine. |
| `/about` | Project notes and architecture links. |

## Stack

- React 19 + TanStack Start and TanStack Router.
- Tailwind CSS v4 + shadcn primitives.
- Rust/WASM bridge from `../wasm`.
- Cloudflare Workers deployment via Wrangler.
- Package manager: `bun`.

## Commands

```bash
bun install
bun --bun run dev
bun --bun run test
bun --bun run build
```

WASM refresh after Rust exports change:

```bash
bun run wasm
```

Net-enabled Wall Chess WASM refresh:

```bash
bun run wasm:net
```

## Current product state

- User-facing shell is **Gameboard**.
- Wall Chess is the deployed mature game, with the alpha-beta bot as the strongest path.
- International Draughts is playable in-browser through Rust/WASM and the Gen-1 search bot.
- The Cloudflare Worker/package name still contains `wallchess` for deployment continuity. Rename it only during an explicit deployment cutover.

## Development notes

- `src/routeTree.gen.ts` is generated by TanStack Router. Do not edit it manually.
- `src/game/checkers.ts` is intentionally a thin WASM wrapper. Do not reimplement draughts rules in TypeScript.
- `src/game/engine.ts` remains the browser-side Wall Chess rules engine used by UI flows and tests.
- Keep board UI copy short. The board state should carry most of the explanation.
